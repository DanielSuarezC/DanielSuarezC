### 💳 PagoFácil

Prototipo de sistema de pagos digitales accesible, diseñado pensando especialmente en personas no bancarizadas o con baja alfabetización digital.

Incluye flujo guiado de pagos, comprobantes, historial de movimientos, persistencia local, diseño responsive y pruebas automatizadas.

**Tecnologías:** React · TypeScript · Vite · Tailwind CSS · React Router · Vitest

[🔗 Ver proyecto](https://github.com/DanielSuarezC/pagofacil)

---

### 📡 Sistema IoT de Inventario y POS

Sistema completo que conecta hardware físico con una plataforma de inventario y punto de venta.

Integra:

* Arduino Uno
* Lector de códigos de barras
* Comunicación serial
* Bridge local con Node.js
* Backend
* Frontend Angular
* Docker
* Comunicación mediante API

Este proyecto representa uno de mis principales enfoques: **conectar software con problemas reales del mundo físico**.

**Tecnologías:** Arduino · Node.js · Angular · TypeScript · APIs · Docker

[🔗 Ver proyecto](https://github.com/DanielSuarezC/app-lector)

---

### ♟️ Sports Club Manager

Plataforma para la administración de clubes, jugadores, entrenadores y eventos deportivos.

El proyecto cuenta con una arquitectura frontend/backend y funcionalidades como autenticación JWT, gestión de roles, CRUD, eventos, clubes y persistencia en MySQL.

**Tecnologías:** Angular · Java · Spring Boot · MySQL · JPA · JWT · Maven

[🔗 Frontend](https://github.com/DanielSuarezC/Sports-Club-Manager)
[🔗 Backend](https://github.com/DanielSuarezC/sportsclubmanager-backend)
